# Mi Página Web

## Descripción

Este proyecto consiste en una página web creada como parte de un proyecto escolar. La página busca presentar información de forma sencilla, organizada y fácil de entender.

## Objetivo

El objetivo del proyecto es aprender a crear y organizar una página web utilizando herramientas de desarrollo web como HTML, CSS y JavaScript, además de aprender a utilizar GitHub para almacenar y gestionar el proyecto.
